Online DJ Booking System – QA SDLC Report

Project Overview
This project focuses on testing an Online DJ Booking System where users can browse and book DJs for events such as weddings, parties, and celebrations. The system includes features like user registration, login, viewing DJs, adding to cart, booking, payment, and booking history.

SDLC Phases
1 Requirement Analysis
2 Test Planning
3 Test Design
4 Development
5 Testing
6 Deployment

Functional Modules
1 User Registration – User signup with basic details
2 Login & Logout – Authentication functionality
3 Home Page – View available DJs and details
4 Cart Module – Add and manage selected DJs
5 Booking Module – Book selected DJ services
6 Payment Module – Complete payment process
7 Booking Confirmation – Confirmation after successful booking
8 Booking History / Dashboard – View past bookings

Non-Functional Requirements
1 Performance: Pages should load within 2–3 seconds
2 Usability: Simple UI and easy navigation
3 Reliability: No crashes and proper data handling
4 Security: Protect user and payment information

Test Approach
1 Functional Testing
2 UI Testing
3 Integration Testing
4 Regression Testing

Conclusion
The system has been analyzed and planned for testing across all modules including registration, login, cart, booking, payment, and history. The test plan ensures that all functionalities will be validated effectively. The system is ready for the next phase of testing.
